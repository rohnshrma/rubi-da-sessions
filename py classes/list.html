Python Lists

Many values, one basket

Collections

A normal variable holds one value. A collection holds many values in one variable, and these values can be of the same or different data types.

Python gives us four built-in collections:

TypeBracketsOrderedIndexedChangeableDuplicates
List[ ]YesYesYesYes
Tuple( )YesYesNoYes
Set{ }NoNoAdd / remove onlyNo
Dictionary{key: value}YesBy keyYesNo duplicate keys
Note: In a set we can add or remove items, but we cannot change an item in place, because there is no index to reach it.

What is a List?

We make a list with square brackets [ ] and separate the items with commas. Think of it as a row of baskets kept in a fixed line, each one with a number.

A list is ordered, indexed, mutable (changeable) and it allows duplicates.

marks = [23, 56, 67, 34, 67, 89]   # list of 6 marks; 67 appears twice

print(type(marks), len(marks))     # type() tells the data type, len() counts the items
<class 'list'> 6
print(marks)   # items come out in the same order we put them in, 67 is kept twice
[23, 56, 67, 34, 67, 89]

Indexing

Every item has a position called its index. Counting starts from 0, not 1. So the first item is marks[0].

print(marks[0])   # first item
print(marks[2])   # third item (index 2)
23 67
Tip: Negative index counts from the end. marks[-1] gives the last item.

Changing an Item

Lists are mutable, so we can replace any item by using its index.

marks[3] = 64   # 34 at index 3 is replaced with 64
print(marks)
[23, 56, 67, 64, 67, 89]

Adding Items

append() : one item at the end

marks.append(100)   # 100 is added after the last item
print(marks)
[23, 56, 67, 64, 67, 89, 100]

insert() : one item at a chosen position

marks.insert(3, 99)   # insert(index, item): 99 goes to index 3, others move right
print(marks)
[23, 56, 67, 99, 64, 67, 89, 100]

extend() : many items at the end

marks.extend([56, 56, 56])   # every item of the given list is added at the end
print(marks)
[23, 56, 67, 99, 64, 67, 89, 100, 56, 56, 56]
append vs extend: append([1, 2]) adds the whole list as one item. extend([1, 2]) adds 1 and 2 separately.

Removing Items

pop() : remove by index

Without an index it removes the last item. With an index it removes the item at that position. It also returns the removed item.

marks.pop()    # removes the last item (56)
marks.pop(0)   # removes the item at index 0 (23)
print(marks)
[56, 67, 99, 64, 67, 89, 100, 56, 56]

remove() : remove by value

It removes only the first match of the value.

marks.remove(56)   # only the first 56 goes, the other two stay
print(marks)
[67, 99, 64, 67, 89, 100, 56, 56]
marks.remove(1000)   # 1000 is not in the list, so Python raises an error
ValueError: list.remove(x): x not in list
Safe way: check first with if 1000 in marks: marks.remove(1000)

Searching

count() : how many times

print(marks.count(56))   # 56 appears 2 times
2

index() : where is it

print(marks.index(56))   # position of the first 56
6

Reversing and Sorting

reverse() : flip the order

marks.reverse()   # last item becomes first; no sorting happens
print(marks)
[56, 56, 100, 89, 67, 64, 99, 67]

sort() : arrange the items

marks.sort()               # ascending by default: small to big
print(marks)

marks.sort(reverse=True)   # reverse=True gives descending: big to small
print(marks)
[56, 56, 64, 67, 67, 89, 99, 100] [100, 99, 89, 67, 67, 64, 56, 56]
Remember: sort() and reverse() change the original list and return None. Writing x = marks.sort() will give x = None.

Copy and Clear

copy() : a separate duplicate

x = marks.copy()   # x is a new list with the same items
print(x)
[100, 99, 89, 67, 67, 64, 56, 56]
Why not just x = marks? That does not make a copy. Both names point to the same list, so a change in one shows up in the other. copy() keeps them apart.

clear() : empty the list

x.clear()   # removes every item, the list itself still exists
x           # in Jupyter, the last line's value is shown
[]

Since x was a copy, marks still has all its items.

In the same list, add "guava" at the end and "kiwi" at the start.

7. Fix a wrong mark Medium

In marks = [35, 72, 58] the 35 was entered by mistake. Change it to 40 without typing its index yourself.

8. Remove without error Medium

items = ["book", "pencil"]. Write code that removes "pen" only if it is present, so the program never crashes.

Show answer 
items = ["book", "pencil"]
if "pen" in items:      # 'in' checks if the item exists
    items.remove("pen")
print(items)            # nothing removed, and no error
['book', 'pencil']

9. Guess the output Tricky

Without running it, what will this print? Then change one line so a stays the same.

a = [1, 2, 3]
b = a
b.append(4)
print(a)
Show answer
[1, 2, 3, 4]

b = a does not copy. Both names point to the same list, so a changes too. Fix:

a = [1, 2, 3]
b = a.copy()   # b is now a separate list
b.append(4)
print(a)       # a is safe
[1, 2, 3]

10. Topper and lowest Tricky

For marks = [67, 89, 45, 92, 58], print the highest and lowest marks using only list methods (no max() or min()). Keep the original list unchanged.

Show answer 
marks = [67, 89, 45, 92, 58]
sorted_marks = marks.copy()   # copy first so the original order is kept
sorted_marks.sort()           # small to big
print("Lowest:", sorted_marks[0])     # first item after sorting
print("Highest:", sorted_marks[-1])   # last item after sorting
print(marks)                          # original is unchanged
Lowest: 45 Highest: 92 [67, 89, 45, 92, 58]
